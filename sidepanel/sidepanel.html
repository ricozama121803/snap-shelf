    How to use Snap Shelf

    Save things

    • Highlight text, then right-click → Save selection to Snap Shelf
    • Right-click an image → Save image to Snap Shelf
    • Right-click empty space → Capture screenshot region, or press Ctrl+Shift+S (Cmd+Shift+S on Mac), then drag to select

    Organize

    • Use the filter chips, tag filter, and search to find items
    • Folder icon: create, rename, or delete folders
    • Grid icon: gallery view of screenshots and images

    Keyboard shortcuts

    • / search · ↑↓ move between items
    • Enter open original page · F favorite
    • C copy · E edit · Del delete
    • Esc clear search or close a dialog
